# 📝 BoardExam2 - 두번째 게시판 프로젝트

학원에서 배운 기술을 활용하여 제작한 두번째 게시판 프로젝트입니다.

## 소개
* 프로젝트명: BoardExam2 (두번째 게시판)
* 개발 형태: 수업 실습 프로젝트
* 개발 기간: 2025-03-26부터 시작
* 목적: 첫번째 게시판 프로젝트의 개선 및 추가 기능 구현

## 사용 기술
* Language: Java 17
* Database: MariaDB
* Frontend: HTML
* Template Engine: Thymeleaf
* 기타: Bootstrap 5 (UI 스타일링)

## 주요 기능

### 게시글 관리
* 게시글 목록 조회
* 게시글 작성
* 게시글 상세 보기
* 게시글 수정
* 게시글 삭제

### 기본 기능
* 페이징 처리
* 게시글 번호 자동 생성
* 작성일자 표시
